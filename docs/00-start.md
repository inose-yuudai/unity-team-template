# 最初にやること（チームを始める）

チームを作ったら、最初にこのページの順番で準備します。
GitHub（みんなのファイルを置く場所）と、Notion（やることの一覧）の 2 つを用意します。

| 順番 | やること | だれが | くわしい手順 |
|---|---|---|---|
| 1 | 役割を決める（リーダーを 1 人） | 全員 | このページの「1」 |
| 2 | GitHub と Notion のアカウントを作る | 全員 | このページの「2」 |
| 3 | GitHub のチームのリポジトリを作る | リーダー | [はじめての準備](01-setup.md) の「2」 |
| 4 | Notion のチームのボードを作る | リーダー | このページの「4」 |
| 5 | 2 つを、おたがいにつなぐ | リーダー | このページの「5」 |
| 6 | 道具を入れて、Unity のプロジェクトを用意する | 全員 | [はじめての準備](01-setup.md) の「1」「3」〜「6」 |

## 1. 役割を決める（全員）

- リーダーを 1 人決めます。リーダーは、GitHub のリポジトリと Notion のボードを作る人です。
- Unity のバージョンを確かめます。先生から指定がなければ、チームで 1 つに決めます。

## 2. アカウントを作る（全員）

| サービス | 入手先 | リーダーに伝えること |
|---|---|---|
| GitHub | https://github.com/ | GitHub のユーザー名 |
| Notion | https://www.notion.so/ | Notion に登録したメールアドレス |

- どちらも無料のプランで使えます。
- リーダーは、先生の GitHub のユーザー名と、Notion のメールアドレスも聞いておきます。

## 3. GitHub のチームのリポジトリを作る（リーダー）

[はじめての準備](01-setup.md) の「2」を見て進めます。仲間と先生を招待するところまでやります。

## 4. Notion のチームのボードを作る（リーダー）

1. Notion にログインした状態で、ボードの雛形のページを開く
   - https://ninth-parsley-0e9.notion.site/4040c5c99fe581d48112f404ede2afd6
2. 右上の「複製」を押す
3. 「どこに複製するか」を聞かれたら、自分のワークスペースを選ぶ
4. 複製できたら、ページの名前を「（チーム名）の開発ボード」に変える
5. 右上の「共有」を押し、仲間と先生のメールアドレスを入れて招待する
   - 権限は「編集権限」にします（タスクを書いたり動かしたりできます）。
6. 仲間は、届いたメールから Notion のページを開く

複製したページは、自分のワークスペースの物です。元の雛形は、ほかのチームも使うので書き換わりません。

## 5. GitHub と Notion をつなぐ（リーダー）

おたがいの URL を貼っておくと、行き来しやすくなります。

1. Notion のボードの「チーム」の表の「GitHub のリポジトリ」に、リポジトリの URL を貼る
2. Notion のボードの右上の「共有」→「リンクをコピー」で、ボードの URL をコピーする
3. GitHub のリポジトリの README の「タスクの一覧（Notion）」に、その URL を貼る
   - README を直す時は、GitHub のページで README を開き、右上のえんぴつのボタンから直せます。準備の間は、main に直接コミットして大丈夫です。

## 6. 道具を入れて、Unity のプロジェクトを用意する（全員）

[はじめての準備](01-setup.md) の「1」と「3」〜「6」を進めます。
Notion のボードの「準備」のタスクにも同じことが書いてあるので、終わったら「完了」にしていきましょう。

## 準備ができたら

- [チームの決まり](03-team-rules.md) を、全員で読む
- [毎日の作業の流れ](02-daily-flow.md) を見ながら、最初のタスクを進める
